# Chat Clash mark

`logo.png`: 1024 × 1024 transparent RGBA PNG. `favicon.png`: 64 × 64.
`favicon.ico`: 16, 32, 48 and 64 px. All exports preserve transparency.

Generated October 25, 2026 using Codex's built-in image generation tool. The
generated 1254 px source was resampled for the requested exports using Pillow;
no runtime image service is used. The mark is used in the overlay, controls and
project README. No third-party logos or characters were requested.

Generation prompt:

> Use case: logo-brand. Create a finished bold, playful icon mark for Chat Clash,
> a live battle between chat communities. Two chunky speech bubbles collide with
> a crisp spark between them. Simple geometric vector-like silhouette, thick
> dark ink outline plus a thin pale outer keyline so it reads on dark and light
> backgrounds. One bubble warm coral-orange, the other electric mint-green,
> spark warm ivory. Very legible as a tiny 64px app icon, centered square
> composition with generous transparent margins. No words or letters, no
> third-party trademarks, no Twitch logo, no characters, no shadows or extra
> objects. Deliver 1024x1024 with genuine transparent alpha background.
